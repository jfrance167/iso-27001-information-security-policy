# Security and Responsible Use

This is a local educational cryptography lab. It reads and writes only the
paths explicitly supplied to it and does not access accounts, networks, or
third-party systems.

The Caesar cipher provides no meaningful confidentiality. Never use it to
protect passwords, personal information, financial records, or other sensitive
data. Test only with synthetic or public text that you are authorized to use.

Report an accidental disclosure through the repository's private vulnerability
reporting channel rather than a public issue.
