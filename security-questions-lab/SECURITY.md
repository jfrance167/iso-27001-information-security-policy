# Security and Responsible Use

This project is a local, defensive simulation. It is not an OSINT collection,
account-recovery, social-engineering, or identity-research tool.

## Controls

- All profile IDs and outcomes are generated locally and are fictional.
- No names, answers, sources, URLs, usernames, or account identifiers exist.
- The program has no network, browser, authentication, or account-access code.
- Outputs contain only Boolean outcomes and aggregate rankings.
- Participant counts are bounded to prevent accidental resource abuse.
- Every generated row is explicitly labeled as synthetic.

## Prohibited use

- Do not investigate a real person's recovery questions or personal history.
- Do not attempt, automate, or observe an account-recovery flow without the
  system owner's explicit authorization.
- Do not store recovery answers, identity records, private messages, or data
  broker results in this repository.
- Do not use pretexting, impersonation, phishing, leaked datasets, or private
  social-media access.

Organizations should avoid knowledge-based security questions and use stronger,
standards-aligned recovery and authentication mechanisms.

Report repository vulnerabilities through the root security policy.
