# Ethics and Privacy Boundary

The source project includes detailed safeguards for volunteer consent, public
information, anonymous IDs, data destruction, and avoiding private accounts.
This implementation goes further by using no volunteers and performing no
research about real people.

## Permitted extensions

- Change the fictional probabilities and document the assumptions.
- Add invented question categories that cannot identify a person.
- Compare recovery designs conceptually using published aggregate research.
- Test analysis functions using fabricated Boolean records.

## Out of scope

- Searching a person's name, family, school, employer, address, or social media;
- asking people for security questions or answers;
- testing whether an answer works on a website;
- combining public records to identify or profile someone;
- publishing row-level information derived from a person.

Even information visible on the internet can create harm when collected,
combined, or republished. Public availability is not blanket permission for a
student project. A future human-subject study would require advance review,
informed consent, strict minimization, a deletion plan, and a genuinely necessary
research question. It should never include account-recovery attempts.
